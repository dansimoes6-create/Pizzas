# DestaK Pizza e Lanches

Site de apresentação da pizzaria DestaK Pizza e Lanches, em Prado - BA.

## Requisitos

- Node.js 22 ou superior
- npm

## Desenvolvimento local

```sh
npm install
npm run dev
```

## Build de produção

```sh
npm run build
```

## Publicar no Netlify

1. Envie este projeto para um repositório no GitHub.
2. No Netlify, selecione **Add new project → Import an existing project** e conecte o repositório.
3. O arquivo `netlify.toml` configura o comando de build e a pasta de publicação automaticamente.
